### 🎰 Puzzle 03 — Build a Turing Machine (in your head)

A Turing machine reads and writes symbols on an infinite tape using a tiny rulebook. Here is a **binary incrementer** (adds 1 to a binary number). Head starts on the **rightmost** bit.

```text
 TAPE:  ... _ │ 1 │ 0 │ 1 │ 1 │ _ ...
                        ▲ head starts at the last bit

 RULES (state = INC):
   read 1  →  write 0, move LEFT,  stay INC     (carry)
   read 0  →  write 1, HALT                      (done)
   read _  →  write 1, HALT                      (new digit)
```

**Challenge:** run the machine on `1011`. What is the final tape?

<details>
<summary>▶ <b>Reveal answer</b></summary>

`1011` is 11. Add 1 → 12 = **`1100`**.

Trace: 1→0 (carry) · 1→0 (carry) · 0→1 (halt) → `1 1 0 0` ✅

</details>
