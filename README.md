<details>
<summary><b>▶ ./turing_test.ai</b> &nbsp;— Human or Machine? (3 rounds)</summary>

| **B** | Wet dust, kind of metallic, makes me want to nap. |

## `🎰` [4] turing_sim.run

<details>
<summary><b>▶ ./turing_sim.run</b> &nbsp;— be the Turing machine</summary>

<br/>

A Turing machine reads/writes symbols on an infinite tape using a tiny rulebook. This one is a **binary incrementer** (adds 1). The head starts on the **rightmost** bit.

```text
 TAPE:   ... _ │ 1 │ 0 │ 1 │ 1 │ _ ...
                             ▲ head starts here

 RULES  (state = INC)
   read 1  →  write 0, move LEFT, stay INC    (carry)
   read 0  →  write 1, HALT                    (done)
   read _  →  write 1, HALT                    (new digit)
```

**Challenge A:** run it on `1011`. What's the final tape?
**Challenge B:** run it on `111`. What's the final tape?

<details>
<summary>Reveal answers</summary>

- **A:** `1011` (11) + 1 = 12 → **`1100`**. Trace: 1→0, 1→0, 0→1 halt.
- **B:** `111` (7) + 1 = 8 → **`1000`**. Trace: 1→0, 1→0, 1→0, then blank → 1 halt.

</details>
